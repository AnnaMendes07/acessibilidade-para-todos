# ♿ Acessibilidade para Todos

Uma plataforma para encontrar e compartilhar facilidades de acessibilidade. 💜

## ✨ Sobre o projeto

**Acessibilidade para Todos** é um projeto acadêmico desenvolvido em equipe com a proposta de facilitar a localização e a avaliação de estabelecimentos acessíveis.

A ideia é ajudar pessoas com deficiência ou mobilidade reduzida a encontrar locais adequados às suas necessidades com mais segurança, autonomia e confiança.

O projeto utiliza a abordagem de **Design Thinking** para compreender as dificuldades relacionadas à acessibilidade e pensar em uma solução que facilite o acesso a essas informações.

## 🎯 Objetivo

Promover inclusão e autonomia por meio de uma plataforma que conecte pessoas a estabelecimentos acessíveis, incentivando também os negócios a investirem em acessibilidade.

## 🧠 Etapas do projeto

- Pesquisa sobre dificuldades relacionadas à acessibilidade.
- Identificação de necessidades e oportunidades de melhoria.
- Ideação de uma solução por meio do Design Thinking.
- Prototipagem da proposta para visualização da experiência do usuário.
